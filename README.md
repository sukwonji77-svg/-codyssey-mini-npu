

# Mini NPU Simulator

## 1. 프로젝트 개요

Python으로 MAC(Multiply-Accumulate, 곱셈·누산)
연산을 구현하여 Cross(+)와 X 패턴을 판정하는
소형 NPU 시뮬레이터입니다.

## 2. 개발 환경

- OS: Ubuntu (WSL2)
- Language: Python 3.14.4
- Library: Python 표준 라이브러리

## 3. 주요 기능

- 3x3 사용자 입력 모드
- 5x5, 13x13, 25x25 JSON 자동 분석
- MAC 연산을 통한 패턴 분류
- 입력값 및 행렬 크기 검증
- PASS/FAIL 판정
- MAC 연산 시간 측정

## 4. 실행 방법

```bash
python3 main.py
```

1번: 3x3 사용자 입력 모드

2번: data.json 자동 분석 모드

## 5. MAC 연산 원리

입력 행렬과 필터 행렬의 같은 위치에 있는
값을 곱하고 모두 더합니다.

MAC = sum(input[i][j] * filter[i][j])

두 필터의 점수를 비교하여 더 높은 쪽으로
패턴을 분류합니다.

점수 차이가 1e-9 미만이면 동점으로 처리합니다.

## 6. JSON 테스트 결과

| 패턴 | 판정 | 결과 |
|---|---|---|
| size_5_1 | UNDECIDED | FAIL |
| size_5_2 | Cross | PASS |
| size_13_1 | X | PASS |
| size_13_2 | UNDECIDED | FAIL |
| size_25_1 | UNDECIDED | FAIL |
| size_25_2 | Cross | PASS |

총 6개 중 PASS 3개, FAIL 3개입니다.

FAIL 3개는 Cross와 X의 MAC 점수 차이가
허용오차 이내여서 UNDECIDED로 판정된 사례입니다.

## 7. 성능 분석

Python의 `time.perf_counter()`를 이용하여 각 크기별 MAC 연산을 100회 반복하고 평균 실행 시간을 측정하였다.

| 행렬 크기 | 평균 실행 시간(ms) | MAC 연산 횟수 |
|---|---:|---:|
| 3×3 | 0.000559 | 9 |
| 5×5 | 0.001383 | 25 |
| 13×13 | 0.007327 | 169 |
| 25×25 | 0.023661 | 625 |

### 분석 결과

- 5×5에서 25×25로 행렬 크기가 5배 증가하면 MAC 연산 횟수는 25배 증가한다.
- 실제 평균 실행 시간은 약 17.1배 증가하였다.
- MAC 연산은 이중 반복문으로 구현되어 시간 복잡도가 O(N²)이다.
- 실제 실행 시간은 Python 인터프리터의 실행 비용과 시스템 환경에 따라 차이가 발생할 수 있다.

### JSON 테스트 결과

총 6개 테스트 중 PASS 3개, FAIL 3개가 발생하였다.

실패 사례는 `size_5_1`, `size_13_2`, `size_25_1`이며, 모두 두 필터의 MAC 점수 차이가 허용오차 `1e-9` 이내여서 `UNDECIDED`로 판정되었다.

따라서 실패는 프로그램 실행 오류가 아니라 현재 MAC 점수 비교 및 동점 처리 정책에 따른 결과이다.
